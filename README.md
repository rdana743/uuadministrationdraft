# UU CMS

Интерактивный прототип единой административной панели для сайтов Universal University.

Откройте `index.html` в браузере. Выберите сайт, откройте страницу и попробуйте отредактировать её блоки. Черновики и демопубликации хранятся локально в браузере. Прототип использует демонстрационные данные.

[Архитектура и подключение сайтов](ARCHITECTURE.md)

## Главные страницы

Кнопка «Редактор главных» открывает сохранённый HTML одного из десяти сайтов. Выберите элемент кликом в предпросмотре или найдите его по тексту, тегу или ID. В инспекторе доступны текст, ссылки, изображения, подписи, поля форм, CSS-классы и встроенные стили. Правки каждого сайта хранятся в браузере. Исходные CSS, изображения и шрифты могут загружаться с публичных серверов.

Админка загружает только выбранную страницу и держит открытые снимки в памяти до перезагрузки. Кнопка «Экспорт HTML» показывает весь код текущего снимка с внесёнными правками, в том числе несохранёнными. Код можно скопировать или скачать отдельным файлом. Таблицы стилей и медиа сохраняют ссылки на источники.

Снимки содержат элементы из исходного HTML. Скрипты, сторонние iframe и отправка форм отключены. Блоки, которые оригинал создаёт только через JavaScript, в снимок не попадают. Правки не отправляются в CMS. Если снимок обновится, правки предыдущей версии автоматически не переносятся.

Обновление снимков:

```sh
python3 -m pip install beautifulsoup4 html5lib
python3 tools/import-homepages.py
```
